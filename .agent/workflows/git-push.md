---
// turbo-all
1. Stage all changes:
   ```bash
   git add .
   ```
2. Commit changes with a descriptive message:
   ```bash
   git commit -m "Update: [Brief description of changes]"
   ```
3. Push to the remote repository:
   ```bash
   git push origin main
   ```
